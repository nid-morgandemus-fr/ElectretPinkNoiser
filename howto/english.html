📋 The 7 Protocol Steps

Follow these steps in order, without skipping any. Rigor is the key to reproducibility.

🔧 Equipment Preparation

  • Install Python and libraries (numpy scipy matplotlib)
  • Prepare speaker, recorder, soldered capsules
  • Identify a known-good reference capsule

🎵 Pink Noise Generation

  • Run: python3 generate_pink_noise.py -d 10 -r 44100 -o pink_noise.wav
  • Parameters: 10s, 44.1 kHz, WAV 16 bits
  • Copy file to USB drive or keep on computer

📍 Device Setup

  • Speaker on stable surface
  • Mark capsule position at 30 cm
  • Quiet room, windows closed, no fans
  • Check recording levels (no saturation)

🎯 Reference Recording

  • Place reference capsule at marked position
  • Start pink noise playback
  • Record 10 seconds → reference_capsule.wav
  • Listen to verify: sound present, not saturated

🧪 Capsule Testing

  • Place each capsule EXACTLY at the same position
  • Record 10s → capsule_001.wav, capsule_002.wav...
  • DO NOT move speaker or change volume

📊 Comparative Analysis

  • Gather all WAV files in one folder
  • Run: python3 analyze_capsules.py -i ./recordings/ -o report.pdf
  • Script generates PDF with superimposed spectra and RMS table

✅ Results Interpretation

  • COMPLIANT: RMS within tolerance (±6 dB)
  • REJECTED: RMS deviates more than 6 dB from average
  • Check spectra: irregularities = suspicious
  • Archive PDF report for traceability

🎯 Acceptance Criteria

Three possible verdicts for each tested capsule. Tolerance is ±6 dB around the average.

✅ COMPLIANT

  • RMS within tolerance (±6 dB)
  • Regular frequency spectrum
  • No peaks > 3 dB
  • Acceptable noise floor (SNR > 40 dB)
  • Correct tap test response

⚠️ TO VERIFY

  • RMS between 3 and 6 dB deviation
  • Spectrum with some irregularities
  • Redo test to confirm
  • Check positioning

❌ REJECTED

  • RMS > 6 dB deviation from average
  • Very irregular or flat spectrum
  • No tap test response
  • Excessive noise floor
  • Short-circuit or open circuit

⌨️ Useful Commands

Commands to copy-paste in your terminal. Remember to adapt paths.

Generate pink noise

bash python3 generate_pink_noise.py -d 10 -r 44100 -o pink_noise.wav
bash python3 generate_pink_noise.py --duration 30 --rate 48000 --output test.wav
bash python3 generate_pink_noise.py --voss # More precise algorithm

Analyze capsules

bash python3 analyze_capsules.py -i ./recordings/ -o report.pdf
bash python3 analyze_capsules.py --input-dir ./tests/ --threshold 3.0
bash python3 analyze_capsules.py --pattern "capsule_*.wav"

Check files

bash ls -lh *.wav
bash file pink_noise.wav
bash soxi pink_noise.wav # If sox is installed

⚠️ Method Limitations

Let's be honest: this method is a quick sorting tool, not a metrology instrument.

  • ⚠️ Does not replace professional calibration
  • ⚠️ Cannot measure directivity
  • ⚠️ Cannot measure harmonic distortion (THD)
  • ⚠️ Sensitive to room acoustic conditions
  • ✅ Perfectly adapted for quick sorting in artisanal production
